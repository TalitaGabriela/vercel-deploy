# vercel-deploy

Laboratório de Deploy PaaS (Vercel) - disciplina de Computação em Nuvem.

## Descrição

Projeto em Next.js com:

- **Relógio digital / contador regressivo** para o fim do semestre, em dias, horas, minutos e segundos, atualizando em tempo real.
- **Timeline** com os trabalhos desenvolvidos em cada semestre do curso (TADS 01 a TADS 04).

## Tecnologias

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Vercel (deploy)

## Como rodar localmente

```bash
npm install
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000).

Publicado na Vercel como projeto PaaS.
